Example 1: Photo Timeline Tracker (Singly Linked List)

Insert: O(1) | Print: O(n) | Search: O(n)

Problem: Swift's been watching Link Click - a Chinese thriller where two friends run a photo studio with the power to dive into photographs and experience past events. Each photo they enter is linked to a moment in time, forming a chain of events. Let's build a photo timeline tracker using a singly linked list to store photos in chronological order.

In Link Click, Cheng Xiaoshi can jump into photos and live through the photographer's perspective for exactly 12 hours. Each photo represents a "node" in time, and they're connected in sequence - perfect for a linked list!

We need to:

  • Add new photos to the timeline (most recently processed appears first)
  • Print all photos in the timeline
  • Search for a specific photo by location

Step 1: Define the Node Structure

Each photo node needs a location, timestamp (year), and a pointer to the next photo in the timeline.

struct PhotoNode {
    string location;
    int year;
    PhotoNode* next;
};

Step 2: Implement Insert at Front (O(1))

Adding to the front is fast - just update the head pointer.

void insertFront(PhotoNode*& head, string location, int year) {
    PhotoNode* newNode = new PhotoNode;
    newNode->location = location;
    newNode->year = year;
    newNode->next = head;  // New node points to old head
    head = newNode;        // Head now points to new node
}

Step 3: Implement Print Function (O(n))

Go through every photo and print its data.

void printTimeline(PhotoNode* head) {
    if (head == NULL) {
        cout << "No photos in timeline!" << endl;
        return;
    }

    PhotoNode* current = head;
    cout << "=== Photo Timeline (Time Photo Studio) ===" << endl;
    while (current != NULL) {
        cout << "Photo at " << current->location
             << " (Year: " << current->year << ")" << endl;
        current = current->next;
    }
}

Step 4: Implement Search Function (O(n))

Look through the timeline to find a specific photo by location.

bool searchPhoto(PhotoNode* head, string location) {
    PhotoNode* current = head;
    while (current != NULL) {
        if (current->location == location) {
            cout << "Found photo at " << location
                 << " (Year: " << current->year << ")" << endl;
            return true;
        }
        current = current->next;
    }
    cout << "Photo at " << location << " not found in timeline." << endl;
    return false;
}

Why It Works:

  • Insert at front is O(1): We don't need to go through the list - just update two pointers
  • Most recently processed appears first: Because we always insert at the head
  • Search is O(n): In the worst case, the photo is at the end or not in the timeline
  • Dynamic size: We can add as many photos as clients bring without pre-allocating space
  • Perfect for Link Click: Each photo is a "node" linking to past events, forming a chain of moments in time!

Example 2: Music Playlist (Doubly Linked List)

Insert: O(1) | Forward/Backward: O(n) | Delete: O(1) if node given

Problem: Swift's been listening to Fally Ipupa - a Congolese Rumba artist with incredibly smooth vocals. Let's build a music playlist using a doubly linked list so we can skip forward OR go back to the previous song.

Each song needs to know both the next song AND the previous song in the playlist.

Step 1: Define Doubly Linked Node

struct SongNode {
    string title;
    string artist;
    int duration;  // seconds
    SongNode* next;
    SongNode* prev;
};

Step 2: Insert at Back (O(1) with tail pointer)

We keep both head and tail pointers for fast insertion at both ends.

void insertBack(SongNode*& head, SongNode*& tail,
                string title, string artist, int duration) {
    SongNode* newNode = new SongNode;
    newNode->title = title;
    newNode->artist = artist;
    newNode->duration = duration;
    newNode->next = NULL;
    newNode->prev = tail;

    if (tail != NULL) {
        tail->next = newNode;  // Old tail points forward to new
    } else {
        head = newNode;  // List was empty
    }
    tail = newNode;  // Update tail
}

Step 3: Print Forward and Backward

void printForward(SongNode* head) {
    cout << "=== Playing Forward ===" << endl;
    SongNode* current = head;
    while (current != NULL) {
        cout << current->title << " by " << current->artist
             << " (" << current->duration << "s)" << endl;
        current = current->next;
    }
}

void printBackward(SongNode* tail) {
    cout << "=== Playing Backward ===" << endl;
    SongNode* current = tail;
    while (current != NULL) {
        cout << current->title << " by " << current->artist
             << " (" << current->duration << "s)" << endl;
        current = current->prev;
    }
}

Why Use a Doubly Linked List?

  • Bidirectional traversal: Can play songs forward or backward in the playlist
  • Easy "previous" button: Just follow the prev pointer
  • Easier deletion: Don't need to find the previous node - you already have prev
  • Trade-off: Uses more memory (two pointers per node instead of one)

Example 3: Find the Bug - Memory Leak in Destructor

Problem: Swift was helping a student implement a photo timeline destructor for their Link Click-inspired app. The student's code compiles but has a use-after-free bug. Can you spot it before seeing the solution? 

#include <iostream>
#include <string>
using namespace std;

struct PhotoNode {
    string location;
    PhotoNode* next;
};

class PhotoTimeline {
private:
    PhotoNode* head;

public:
    PhotoTimeline() { head = NULL; }

    void addPhoto(string location) {
        PhotoNode* newNode = new PhotoNode;
        newNode->location = location;
        newNode->next = head;
        head = newNode;
    }

    ~PhotoTimeline() {
        PhotoNode* current = head;
        while (current != NULL) {
            delete current;
            current = current->next;
        }
    }
};

int main() {
    PhotoTimeline timeline;
    timeline.addPhoto("Old Apartment");
    timeline.addPhoto("University Campus");
    timeline.addPhoto("City Cafe");

    return 0;
}

The Bug:

After delete current, we try to access current->next. This is accessing freed memory (use-after-free), which causes undefined behavior.

Why It's Dangerous:

  • Accessing freed memory is undefined behavior - might crash, might work, might corrupt data
  • Valgrind would report this as "invalid read"
  • On some systems it appears to work, but it's still wrong

Correct Version:

~PhotoTimeline() {
    PhotoNode* current = head;
    while (current != NULL) {
        PhotoNode* temp = current->next;  // Save next BEFORE deleting
        delete current;                   // Delete current
        current = temp;                   // Move to saved next
    }
}

The Pattern:

Always save what you need BEFORE calling delete!

This is one of the most common bugs in linked list code. Remember: once you call delete, that memory is gone.

Example 4: Round-Robin Task Scheduler (Circular Linked List)

Insert: O(1) | Rotate: O(1) | No NULL pointers!

Problem: Swift needs to schedule tutoring sessions in a round-robin fashion. After the last student, loop back to the first student. This is perfect for a circular linked list!

What's different about circular lists:
  • The last node points back to the first node (no NULL)
  • We use a tail pointer instead of head
  • tail->next gives us the first node
  • Must use do-while loops for traversal

Step 1: Define Node and Insert

struct StudentNode {
    string name;
    StudentNode* next;
};

void insertBack(StudentNode*& tail, string name) {
    StudentNode* newNode = new StudentNode;
    newNode->name = name;

    if (tail == NULL) {
        // First node - points to itself
        tail = newNode;
        tail->next = tail;
    } else {
        // Insert after tail
        newNode->next = tail->next;  // New node points to first
        tail->next = newNode;        // Old tail points to new
        tail = newNode;              // Update tail
    }
}

Step 2: Print All Students (do-while pattern)

void printSchedule(StudentNode* tail) {
    if (tail == NULL) {
        cout << "No students scheduled." << endl;
        return;
    }

    StudentNode* current = tail->next;  // Start at "first"
    cout << "=== Round-Robin Schedule ===" << endl;
    do {
        cout << "- " << current->name << endl;
        current = current->next;
    } while (current != tail->next);  // Stop when back at start
}

Step 3: Rotate Schedule

Move to the next student in the rotation.

void rotate(StudentNode*& tail) {
    if (tail != NULL) {
        tail = tail->next;  // Just move tail forward!
        cout << "Next student: " << tail->next->name << endl;
    }
}

Step 4: Complete Program

#include <iostream>
#include <string>
using namespace std;

struct StudentNode {
    string name;
    StudentNode* next;
};

void insertBack(StudentNode*& tail, string name) {
    StudentNode* newNode = new StudentNode;
    newNode->name = name;

    if (tail == NULL) {
        tail = newNode;
        tail->next = tail;
    } else {
        newNode->next = tail->next;
        tail->next = newNode;
        tail = newNode;
    }
}

void printSchedule(StudentNode* tail) {
    if (tail == NULL) {
        cout << "No students scheduled." << endl;
        return;
    }

    StudentNode* current = tail->next;
    cout << "=== Round-Robin Schedule ===" << endl;
    do {
        cout << "- " << current->name << endl;
        current = current->next;
    } while (current != tail->next);
}

void rotate(StudentNode*& tail) {
    if (tail != NULL) {
        tail = tail->next;
        cout << "Next student: " << tail->next->name << endl;
    }
}

int main() {
    StudentNode* schedule = NULL;

    insertBack(schedule, "Thabo");
    insertBack(schedule, "Amahle");
    insertBack(schedule, "Brandon");

    printSchedule(schedule);
    cout << endl;

    // Rotate through students
    rotate(schedule);
    rotate(schedule);
    rotate(schedule);  // Back to Thabo!

    return 0;
}

Expected Output:

=== Round-Robin Schedule ===
- Thabo
- Amahle
- Brandon

Next student: Amahle
Next student: Brandon
Next student: Thabo

Why Circular Lists Are Perfect for Round-Robin:

  • No end: After the last student, automatically loop back to the first
  • Rotate is O(1): Just move the tail pointer forward
  • Fair scheduling: Everyone gets equal turns in order
  • Real-world use: Operating systems use this for CPU scheduling!

Example 5: Find the Bug - Nothing Prints

Problem: A student wrote this code to print a circular linked list of their tutoring students. The code compiles without errors, but when they run it, nothing prints at all. Can you find the bug? 

void printList(StudentNode* tail) {
    if (tail == NULL) return;

    StudentNode* current = tail->next;

    while (current != tail->next) {
        cout << current->name << endl;
        current = current->next;
    }
}

The Bug:

The while loop checks the condition before running the loop body. Since we start with current = tail->next, the condition current != tail->next is immediately false. The loop never runs at all - nothing gets printed!

This is different from an infinite loop. The program doesn't hang - it just skips all the nodes because the termination condition is met before the first iteration even starts.

Correct Version (using do-while):

void printList(StudentNode* tail) {
    if (tail == NULL) return;

    StudentNode* current = tail->next;

    do {                                // Run body FIRST
        cout << current->name << endl;
        current = current->next;
    } while (current != tail->next);    // Then check condition
}

The Lesson:

Always use do-while for circular linked lists! A while loop checks the condition before running, so it skips the first node. 

Circular List:

tail
 |
 v
[Thabo]--->[Amahle]--->[Brandon]
   ^                       |
   |_______________________|

If we start at tail->next (Thabo) and use while (current != tail->next):
- Initially: current == tail->next (both point to Thabo)
- Condition: current != tail->next is FALSE
- Loop never runs!

With do-while:
- Run body first (print Thabo)
- Then check condition
- Prints all nodes correctly

Summary

You've seen five complete examples showing:

  • Singly Linked Lists: Simple watchlist with insert, print, and search (Example 1)
  • Doubly Linked Lists: Music playlist with forward and backward traversal (Example 2)
  • Use-After-Free Bug: Why you must save next before deleting (Example 3)
  • Circular Linked Lists: Round-robin scheduler with no NULL pointers (Example 4)
  • while vs do-while: Why circular lists need do-while (Example 5)
Key Patterns to Remember:
  • Save next before calling delete
  • Always check for NULL before dereferencing
  • Doubly linked lists update FOUR pointers per insertion
  • Circular lists use do-while for traversal
  • Keep both head and tail pointers when you need fast access to both ends
