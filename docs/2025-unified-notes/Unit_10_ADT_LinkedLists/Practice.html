Problem 4: Count Episodes in Circular List (Intermediate)

You're tracking Gintama episodes in a circular linked list (since it's such a long-running series, you want the playlist to loop back to the start).

Task: Write a function that counts nodes in a circular linked list.

Function signature:

int countCircular(EpisodeNode* tail);

Node structure:

struct EpisodeNode {
    int episodeNum;
    EpisodeNode* next;
};

Important: The parameter is tail (pointer to last node), not head!

Test cases:

  • Empty list (tail = NULL) → returns 0
  • List with 1 node (tail->next points to itself) → returns 1
  • List with 5 nodes → returns 5

Hint: Use a do-while loop and stop when you return to the starting node.

Solution:

For circular lists, we can't check for NULL. Instead, we use a do-while loop and count nodes until we circle back to where we started.

Problem 5: Reverse Doubly Linked List (Challenge)

Write a function that reverses a doubly linked list in place (without creating new nodes).

Task: Reverse the list by swapping next and prev pointers for each node.

Function signature:

void reverseDoubly(Node*& head);

Node structure:

struct Node {
    int data;
    Node* prev;
    Node* next;
};

Example:

  • Original: NULL ← [1] ↔ [2] ↔ [3] → NULL
  • Reversed: NULL ← [3] ↔ [2] ↔ [1] → NULL

Hint: For each node, swap its prev and next pointers. Don't forget to update head at the end!

Solution:

The trick is to swap prev and next for each node as we traverse. At the end, the old tail becomes the new head.

Solution: Reverse Doubly Linked List

Study how we use a temp variable to swap pointers. Try drawing this out on paper!

Click "Run Code" to see the output...

Step-by-step breakdown:

  1. For each node, save prev in temp
  2. Swap: prev becomes next, next becomes prev
  3. Move to next node using current->prev (which is the old next!)
  4. After loop, temp->prev points to the old tail (new head)

Time Complexity: O(n)

Space Complexity: O(1) - In-place reversal!
