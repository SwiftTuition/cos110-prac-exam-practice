🛠️ How to Fix Syntax Highlighting Issues

If syntax highlighting isn't working in your HTML files, follow this checklist:

✓ Step 1: Load Scripts in Correct Order

<script src="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/prism.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/components/prism-c.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/components/prism-cpp.min.js"></script>

Critical: Load prism-c.min.js BEFORE prism-cpp.min.js. C++ depends on C!

✓ Step 2: Place Scripts at End of Body

</div>  <!-- End of content -->

<script src="prism.min.js"></script>
<script src="prism-c.min.js"></script>
<script src="prism-cpp.min.js"></script>
<script>
    Prism.highlightAll();  // Call DIRECTLY, not in DOMContentLoaded
</script>
</body>
</html>

Key point: Don't wrap Prism.highlightAll() in DOMContentLoaded when scripts are at end of body.

✓ Step 3: Use Correct CSS Classes

<pre><code class="language-cpp">
int main() {
    cout << "Hello World" << endl;
    return 0;
}
</code></pre>

Important: Use class="language-cpp" on the <code> tag, not the <pre> tag.

✓ Step 4: Add Token CSS Styling

.token.keyword, .token.class-name { color: #8b5cf6; }  /* Purple */
.token.function { color: #0ea5e9; }  /* Blue */
.token.string { color: #10b981; }  /* Green */
.token.comment { color: #64748b; }  /* Gray */

        return -1;  // Magic error code
    }
    return a / b;

    int result = divide(10, 0);
    if (result == -1) {
        // Handle error
    }

Test 2: Exception Handling Code

class DivisionByZeroException {
private:
    string message;
public:
    DivisionByZeroException(string msg) : message(msg) {}

    string what() const {
        return message;
    }
};

int divide(int a, int b) {
    if (b == 0) {
        throw DivisionByZeroException("Cannot divide by zero!");
    }
    return a / b;
}
