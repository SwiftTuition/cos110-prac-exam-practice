Example 1: Reversing a String with a Stack

Problem

Write a function that uses a stack to reverse a string. For example, "hello" becomes "olleh".

Approach

A stack is perfect for reversing because it's LIFO (Last In, First Out). We push each character onto the stack, then pop them all off. The last character pushed (the last letter) becomes the first character popped (the first letter of the reversed string).

How It Works

  1. Push phase: Loop through the string and push each character. For "hello", we push 'h', 'e', 'l', 'l', 'o'.
  2. Stack state: After pushing, 'o' is at the top, then 'l', 'l', 'e', 'h' at the bottom.
  3. Pop phase: Pop characters and build reversed string. First pop gives 'o', last gives 'h'.
  4. Result: "olleh"
Time Complexity: O(n) - we visit each character exactly twice (once to push, once to pop).
