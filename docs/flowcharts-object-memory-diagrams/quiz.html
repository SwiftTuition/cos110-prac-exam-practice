Finish by drawing

Without the notes, draw in DrawIO the memory diagram of this singly linked list after line 3 (the loop). Each Node holds data and next; the LinkedList holds head. Then check it.

    LinkedList ll;                            // line 1
    for (int i = 1; i <= 4; i++)              // line 2
        ll += i * 10;                         // line 3
  • Stack: ll with one cell, head, pointing at node 10.
  • Heap: four nodes, 10, 20, 30 and 40, each with a data cell and a next cell.
  • Next arrows: 10 to 20, 20 to 30, 30 to 40, and 40 to NULL.
