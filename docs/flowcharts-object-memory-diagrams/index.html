4. Flowcharts, Object Diagrams and Memory Diagrams

COS 110 Theory Exam Notes 2026. Flowcharts for destructors and assignment operators, object diagrams of live objects, memory diagrams of linked lists.

From the exam notice

The theory exam has a DrawIO part: class, object and memory diagrams, and flowcharts.

The 2026 tests asked these diagram questions. You can find each one, with a solution, under From past papers on the Practice page.

  • Flowcharts: a function drawn from a description (Class Test 1), destructors drawn from a class diagram (Class Test 2A and the Logistics mock test), and an assignment operator (Semester Test 1).
  • A recursive flowchart to turn into code (Intervention Test).
  • A class and its constructor from an object diagram and a constructor flowchart (Semester Test 1).
  • Every object after a line of code (Semester Test 1, Semester Test 2 and Class Test 3).

More on class diagrams is in 3. UML Class Diagrams: Reading, Drawing and Coding, if you want it.

Assumed

The exam is closed book. This has not been confirmed in writing. Drawings are made in DrawIO, as in the 2026 tests.
