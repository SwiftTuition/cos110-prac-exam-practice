Binary::isPalindrome (B1-03)

Write bool Binary::isPalindrome(int start, int end) with recursion and no loops (Assumed). It is true when the bits from start to end read the same both ways. A range of one bit or none is true. An invalid start (below 0) or end (>= size) returns false, tested first.

Hint: compare the two outer bits, then call for the range inside them.

#include "Binary.h"

// True when the bits from start to end (both included) read the same in both directions.
bool Binary::isPalindrome(int start, int end) {
    // Invalid input: start or end outside the array.
    if (start < 0 || end >= size) {
        return false;
    }
    // Base case: one bit or no bits left in the range.
    if (start >= end) {
        return true;
    }
    // The two outer bits differ: not a palindrome.
    if (array[start] != array[end]) {
        return false;
    }
    // Recursive case: check the range without the two outer bits.
    return isPalindrome(start + 1, end - 1);
}

Each call moves both ends inward, so start >= end is reached.

Write bool BinaryStrings::remove(const Binary& b). It removes the first string equal to b (the same size and the same bit at every index), and returns true. If none is equal, it returns false. Keep size right, and free the removed node.

#include "BinaryStrings.h"

// Removes the first string in the list that is equal to b: the same size and the
// same bit at every index. Returns true if a node was removed, false otherwise.
bool BinaryStrings::remove(const Binary& b) {
    Node<Binary>* prev = NULL;
    Node<Binary>* curr = head;
    while (curr != NULL) {
        // Compare curr's string with b, bit by bit (Binary has no operator==).
        Binary& data = curr->getData();
        bool same = (data.getSize() == b.getSize());
        for (int i = 0; same && i < b.getSize(); i++) {
            if (data[i] != b[i]) {
                same = false;
            }
        }
        if (same) {
            // Unlink curr: at the front, head moves; otherwise prev skips curr.
            if (prev == NULL) {
                head = curr->next();
            } else {
                prev->next() = curr->next();
            }
            // Deleting the node also destroys its Binary (and so its bool array).
            delete curr;
            size--;
            return true;
        }
        prev = curr;
        curr = curr->next();
    }
    return false;
}
