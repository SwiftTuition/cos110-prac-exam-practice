2. Classes and Object Lifetime

Access, const, static, constructors and initialisation lists, copy constructor, destructor, assignment operator.

This pack covers Lectures 4, 5, 7 and 8 and Tutorials 3 to 5 of COS 110: classes, accessors and mutators, header files, this, const, static, constructors and the initialisation list, automatic type conversion, the copy constructor, the destructor, the assignment operator and object lifetime.

From the COS 110 exam notice

The theory exam on 11 November 2026 is similar to Semester Tests 1 and 2, with a DrawIO part covering class, object and memory diagrams and flowcharts.

Semester Test 1 tested these topics with traces, find-the-errors questions, the three meanings of const, a constructor with an initialisation list, and an operator= flowchart.

Semester Test 1 (26 August 2026) and Class Test 2A (17 August 2026) are this year’s COS 110 tests; questions on these pages that name them follow their patterns.

In the picture below, a filled diamond means the whole owns its parts; a hollow diamond means it only points at parts that live on their own.

A route through the pack

  1. Theory. Thirteen sections, in order. Each ends with a Try this.
  2. Examples. Eight worked examples from Tutorials 3 to 5 and Semester Test 1. Write each answer before you open the solution.
  3. Practice. Sixteen tasks, including two DrawIO flowcharts, then a set of questions from past papers, copied word for word with full solutions.
  4. Quiz. Thirty quick checks.
  5. Topic mock. A 50-mark paper in the shape of Semester Test 1, on these topics only: the question paper (PDF) and the solutions (see Mock test below).

The UML these topics need is explained where it is used. 3. UML Class Diagrams: Reading, Drawing and Coding and 4. Flowcharts, Object Diagrams and Memory Diagrams give more UML practice (optional).
