Finish with an explanation

Without notes, explain to a friend: the three places const can go; when the copy constructor runs and when operator= runs; and what each of the three special functions does with an owned pointer and with a shared pointer.

  • const: on the return type (the caller cannot change what is returned), on a parameter (the function cannot change it), behind the brackets (the function cannot change the object).
  • Copy or assign: the copy constructor makes a new object (Box b2(b1);, Box b3 = b1;, pass by value). operator= changes an object that already exists (b3 = b2;).
  • Owned (composition): the copy constructor and operator= make new copies; the destructor deletes the objects and the array. Shared (aggregation): copies point at the same objects; only the array of pointers is made or deleted.
